# Paper sources

Compile `main.tex` for the main paper or `supplementary.tex` for the separate
supplement. In Overleaf, upload this folder's files and select the corresponding
main document. The full bibliography is `main.bib`; section, figure and table
sources are included locally. Replace the paper ID placeholder before submission.

The main text integrates the UNI/CONCH results, keeps original-grid ranking
diagnostics explicitly labelled, and uses matched4 for the main pathology
comparison. The source's content-page guard was checked with the desktop compiler.
No model, patient or hospital was added by reorganizing these source files.

For numerical summaries see the repository's `results/paper/`. Its referenced
legacy full reproduction archives are separate artifacts, not folders bundled
into this minimal Git repository. Current clean-code validation is recorded in
`provenance/RELEASE_VALIDATION.json`; experiment access and reconstruction are
documented under `docs/`.
